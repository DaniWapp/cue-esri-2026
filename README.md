# CUE Esri Colombia 2026 — Informe

Informe web de **Dani Ismael Rodríguez Gómez** (Ingeniería en TIC, Universidad Libre Seccional Cúcuta) sobre su participación en la Conferencia de Usuarios Esri Colombia 2026 (1 y 2 de octubre, Ágora Bogotá).

**Ver en línea:** https://ingdani.nubecol.com/cue-esri-2026/

## Contenido

- **Informe:** tendencias del evento, casos colombianos y análisis de 11 empresas aliadas de Esri.
- **Biblioteca de saberes:** conceptos SIG, herramientas ArcGIS, datos abiertos de Colombia y ruta de aprendizaje.
- **Contactos:** red de contactos del evento (descarga en .vcf).
- **Documentación:** metodología, fuentes y limitaciones.
- **Videos:** 19 videos cortos del evento.

## Archivos

| Ruta | Descripción |
|---|---|
| `index.html` | Sitio final: estilos, código e imágenes incluidos en un solo archivo |
| `videos/` | Videos del evento (se cargan desde `index.html`) |
| `portada-correo.jpg` | Imagen de portada usada en el correo de presentación |
| `index.src.html` | Fuente editable (las imágenes se enlazan desde `img/`) |
| `img/` | Imágenes optimizadas |
| `herramientas/` | Scripts de Python (OpenCV) para preparar imágenes, videos e ícono y generar `index.html` |

Para publicarlo basta con subir `index.html`, `videos/` y `portada-correo.jpg` a la misma carpeta de un servidor web.
